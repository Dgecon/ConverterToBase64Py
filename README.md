# Base64 File Converter

Графическое приложение на Python для конвертации файлов в строку Base64 с удобным интерфейсом на Tkinter.

## Возможности

* Конвертация одного файла в Base64.
* Пакетная конвертация файлов из директории.
* Фильтрация файлов по расширению.
* Выбор отдельной директории для сохранения результатов.
* Копирование созданных файлов в буфер обмена Windows.
* Копирование содержимого Base64-файла как строки.
* Индикатор прогресса обработки.
* Встроенная справка по использованию.
* Автоматическое добавление текущей даты к имени выходного файла.

## Используемые технологии

* Python 3
* Tkinter
* pyperclip
* pywin32

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/username/base64-file-converter.git
cd base64-file-converter
```

Установите зависимости:

```bash
pip install pyperclip pywin32
```

## Запуск

```bash
python main.py
```

## Режимы работы

### Конвертация одного файла

1. Выберите пункт «Конвертировать один файл».
2. Укажите файл.
3. Программа создаст файл вида:

```text
document-2026-06-04.base64.txt
```

После конвертации доступны действия:

* Копирование результата как файла.
* Копирование содержимого Base64 как текста.
* Копирование пути сохранения.

### Конвертация нескольких файлов

1. Выберите пункт «Конвертировать несколько файлов».
2. При необходимости укажите расширение файлов.
3. Выберите исходную директорию.
4. Запустите конвертацию.

Для каждого файла будет создан отдельный `.base64.txt`.

## Структура выходных файлов

Исходный файл:

```text
report.pdf
```

Результат:

```text
report-2026-06-04.base64.txt
```

Содержимое файла представляет собой строку Base64 исходного файла.

## Особенности

### Буфер обмена Windows

При наличии библиотеки `pywin32` результаты копируются в буфер обмена как реальные файлы, аналогично копированию через Проводник Windows.

После этого их можно вставить сочетанием:

```text
Ctrl + V
```

в любую папку.

### Резервный режим

Если `pywin32` недоступен, программа копирует пути к файлам или их содержимое как обычный текст.

## Требования

* Windows 10/11
